# Demo Guide

## 这个 demo 是什么

这是一个面向**第三方审核工程师**的 **BV PV Design Review Workbench** demo。  
演示主线先聚焦 BV 设计审查工作流，再补充保留的门刚场景模块。  
它的重点不是替代正式设计，而是帮助你快速看懂：

- 当前能否进入下一阶段正式复核
- 控制因素在哪里
- 结论依据是什么
- 下一步要补什么资料

## 3 分钟跑起来

```bash
python -m pip install -e ".[dev]"
python -m streamlit run app.py --server.port 8503
```

打开：

- [http://localhost:8503](http://localhost:8503)

## 建议按这个顺序看

### 1. 先看“BV 审核总览”

重点看：

- `项目概况`
- `审核对象`
- `审核边界`
- `资料完整性`

这一页回答的是：**这次 BV 审核先看什么、边界在哪里、当前资料是否具备进入正式判断的条件。**

### 2. 再看“评估结论”

重点看：

- `初步结构结论`
- `控制因素`
- `关键计算结果`
- `证据状态`

这一页回答的是：**当前项目在现有资料条件下，能不能继续推进到下一轮正式复核。**

![评估结论页](docs/showcase/assets/assessment-overview.png)

### 3. 再看“依据与追溯”

重点看：

- `依据条目`
- `触发条件`
- `证据需求`
- `输入追踪`

这一页回答的是：**为什么会得出这个结论。**

![依据与追溯页](docs/showcase/assets/basis-traceability.png)

### 4. 最后看“报告导出”

重点看：

- Markdown / Word / PDF 导出
- `设计审查报告预览`

这一页回答的是：**这个结果能不能直接变成一个可交付的结构初筛复核摘要，以及设计审查报告预览是否适合进入后续交付整理。**

![报告导出页](docs/showcase/assets/report-export.png)

### 5. 最后补看“门刚场景模块”

这一部分保留用于说明：在 BV 审核主流程之外，demo 仍然带着**门刚场景模块**，用于承接既有门式刚架屋面光伏增载的快速复核输入与结果浏览。

## 这个 demo 当前不做什么

- 不替代正式设计
- 不替代正式结构计算书
- 不替代有限元分析（FEA）
- 不替代盖章/签章审查复核
- 不假装已经自动解析全部图纸、CAD 或现场照片

## 建议怎么理解这版 demo

建议把浏览顺序理解为：

1. BV 审核总览
2. 评估结论
3. 依据与追溯
4. 报告导出
5. 门刚场景模块

看这版 demo，重点不是问“它能不能替代总工”，而是看它是否已经具备了一个工程工具应有的基础能力：

- 有控制路径
- 有保守假设
- 有依据与追溯
- 有可导出的工程化摘要

如果这些成立，它就已经不是一个通用 AI demo，而是一版有工程判断逻辑的产品雏形。
