# Project Brief

## 项目一句话

这是一个面向**既有门式刚架屋面光伏增载**场景的结构初筛复核工具，用于在资料不完整、决策前置的阶段，输出可追溯的工程判断。

## 这个项目想解决什么问题

在既有厂房或仓库加装屋面光伏时，项目往往先卡在“现阶段能不能推进”，而不是直接进入正式设计。

传统上，这类判断依赖资深结构工程师快速结合图纸、证据、经验和规范路径做出前期筛查：

- 当前能否继续推进
- 哪个部位控制
- 缺什么资料
- 是否值得进入下一轮正式复核

这个项目的目标，就是把这类前期结构筛查逻辑数字化。

## 核心能力

- 识别当前控制因素：檩条、主门架梁、主门架柱或连接路径
- 在资料缺失时使用保守假设，而不是直接失效
- 通过 basis 与 traceability 说明“为什么是这个结论”
- 输出结构初筛复核摘要，支持 Markdown / Word / PDF 导出

## 为什么它不是一个通用 AI demo

- 它不是聊天问答驱动的界面
- 它不是简单的 if-else 表单分流
- 它不是直接让大模型生成结论
- 它的底层是**确定性 screening kernel + 规范路径 + 工程假设 + 导出交付**

真正有价值的地方，不是“能不能说得像结构师”，而是“能不能像结构师那样留下控制路径、假设边界和依据链”。

## 当前边界

- 当前聚焦于门式刚架 + 屋面光伏增载场景
- 当前属于 screening-level 结构复核
- 支持 `GB / AISC / Eurocode` 的规范路径选择
- 不替代正式计算书、有限元分析、签章审查或施工图设计

## 为什么这个项目有代表性

这个项目的代表性，不只在于做了一个结构专业 demo，而在于它体现了从问题定义到产品化落地的一整条链路：

- 把真实工程场景收敛成明确产品边界
- 用领域模型和 screening kernel 承载工程判断
- 用 basis / traceability 把结论做成可解释系统
- 用 UI 和导出把结果组织成决策者可消费的形式

因此，这个项目既能体现结构工程判断能力，也能体现工程工具产品化和技术负责人的收口能力。
